# מפת הממשלה — פעילות, תקציב וביצוע

דשבורד שקיפות ציבורי, סטטי ובעברית, על משרדי ממשלת ישראל בתקופת **הממשלה ה-37**
(מ-29 בדצמבר 2022 ועד מועד איסוף הנתונים).

האתר מציג שלושה דברים, ורק אותם:

1. **פעילות פומבית מתועדת** של משרדים והנהלתם — הודעות, עמודים רשמיים, מסמכי מדיניות, פרוטוקולים.
2. **תקציב וביצוע** — תקציב מקורי, תקציב מעודכן, ביצוע ואומדנים, ממקורות רשמיים.
3. **קטלוג מקורות** שניתן לאמת, עם קישור ישיר לכל מסמך.

האתר **אינו** מתיימר לתאר במה עוסקים עובדי המשרדים. יומן פומבי או הודעה לעיתונות מלמדים על מה
שפורסם — לא על היקף עבודה, לא על סדרי עדיפויות פנימיים ולא על תוצאה.

## האתר החי

**https://eyalbenzvi.github.io/GovernmentTracker/**

GitHub Pages מופעל על ה-repository עם Source = GitHub Actions, והפריסה מתבצעת אוטומטית בכל push
לענף העבודה (ראו [פריסה](#פריסה)).

## מצב הנתונים בגרסה הנוכחית

| מה                   | מצב                                                             |
| -------------------- | --------------------------------------------------------------- |
| מקורות רשמיים בקטלוג | **50** — מתוכם 8 אוחזרו עם checksum                             |
| רשומות תקציב וביצוע  | **464** — 5 משרדים × 4 שנות תקציב (2023–2026), רמות היררכיה 1–3 |
| פריטי פעילות פומבית  | **0** — לא נאספו, ראו מגבלה 1                                   |

| נושאים בטקסונומיה    | 12 מוגדרים · 0 מגובים בפריטים                                   |

נתוני התקציב מגיעים ממפתח התקציב — מסד נתונים ציבורי המשקף את נתוני אגף התקציבים במשרד האוצר.
זו **שכבת עזר ולא מקור רשמי ראשוני**, ולכן אף רשומה באתר אינה מסומנת כ"ביצוע סופי": שנים שנסתיימו
מסומנות "נתון חלקי" והשנה השוטפת "אומדן". ספר התקציב ודוחות הביצוע הרשמיים מקוטלגים באתר עם קישור
ישיר, לאימות.

נאספים רק סעיפי **התקציב הרגיל**, שנושאים את שם המשרד עצמו (למשל סעיף 0040 — "משרד התחבורה").
סעיפי תקציב הפיתוח נקראים על שם התחום ולא על שם המשרד (0060 חינוך, 0067 בריאות, 0079 תחבורה,
0076 תעשייה), ושיוכם למשרד אינו נגזר משם הסעיף — ולכן הם אינם נכללים. **המשמעות:** המספרים באתר
הם התקציב הרגיל של המשרד, לא סך ההוצאה הציבורית בתחום. עבור התחבורה בפרט, תקציב הפיתוח גדול
משמעותית מהתקציב הרגיל ואינו מוצג כאן.

בדיקת שפיות שבוצעה: התקציב המקורי של משרד התחבורה לשנת 2025 לפי הנתונים שנאספו הוא
617,993,000 ₪ — זהה למספר שמופיע בהצעת התקציב שפורסמה באתר הכנסת.

## ארכיטקטורה

```
מקורות ציבוריים ─▶ scripts/ (זמן בנייה) ─▶ data/processed/*.json ─▶ אפליקציית React ─▶ GitHub Pages
```

- **אין backend.** אין שרת, אין API פרטי, אין בסיס נתונים, אין התחברות משתמשים, אין מפתחות API.
- **אין קריאות רשת בזמן ריצה.** האתר החי טוען אך ורק קבצים סטטיים מאותו origin.
- **אין LLM בזמן ריצה.** סיווג הנושאים דטרמיניסטי לחלוטין: מילון מילות מפתח + שיוכים ידניים
  מוצהרים, וכל שיוך שומר את הכלל שהפעיל אותו.
- **חלוקת נתונים.** כל dataset נשלח כ-chunk נפרד ונטען בטעינה עצלה, כדי שהאתר יישאר מהיר גם
  כשהנתונים יגדלו לאלפי רשומות.

## טכנולוגיות

React 18 · TypeScript (strict) · Vite 5 · Tailwind CSS 3 · React Router (HashRouter) ·
Recharts · Lucide Icons · Vitest · Playwright · ESLint · Prettier · zod (בזמן בנייה בלבד).

החלטות שכדאי להכיר:

- **HashRouter ולא BrowserRouter** — ל-GitHub Pages אין כללי rewrite, ולכן ניתוב לפי path היה
  מחזיר 404 בקישור עמוק או ברענון. כתובות מהצורה `/#/ministry/transport` עובדות מכל מאחסן סטטי.
- **`base` נגזר אוטומטית** מ-`GITHUB_REPOSITORY` (`vite.config.ts`), כך שאותו קוד עובד גם
  בתת-נתיב של repository וגם בשורש של אתר `<user>.github.io`.
- **בלי webfont חיצוני** — טעינת גופן מ-CDN הייתה קריאה חיצונית בזמן ריצה. מוגדר stack עברי
  (Heebo/Assistant אם מותקנים, אחרת גופן מערכת).
- **zod רק בזמן בנייה** — הוולידציה קפדנית, אבל הספרייה לא נשלחת לדפדפן. האפליקציה מצהירה על
  אותם טיפוסים כ-interfaces, ו-`tests/data-integrity.test.ts` מאמת שקובצי הנתונים מקיימים אותם.
- **שם ה-repository** נשאר `GovernmentTracker`, מפני שהעבודה בוצעה בתוך repository קיים. השם
  המועדף בהוראות היה `government-transparency-map-il`; שינוי שם היה שובר את כתובת ה-Pages
  ואת ה-remote הקיים.

## מקורות הנתונים

לפי סדר עדיפות, כפי שמיושם בקוד:

1. **Gov.il** — עמודי נושא ודוחות ביצוע תקציב.
2. **data.gov.il** — קטלוג הנתונים הפתוחים.
3. **משרד האוצר** — החשב הכללי ואגף התקציבים.
4. **אתר הכנסת** — ספר התקציב ודברי הסבר, ומרכז המחקר והמידע.
5. **מבקר המדינה** — דוחות ביצוע וביקורת.
6. **מפתח התקציב (obudget)** — שכבת עזר בלבד, לזיהוי קודי תקציב ואימות משני. מסומן תמיד
   כ-`secondary_helper`, ונתון שמגיע ממנו לא מסומן לעולם כ-`final`.

הקטלוג המלא, כולל מפרסם, סוג, תקופה, שיטת גילוי, כלל המיפוי וסטטוס האחזור של כל פריט, זמין
במסך "מקורות" באתר וב-`data/processed/source-catalog.json`.

המשרדים שנכללו בגרסה זו, עם סעיף התקציב הרגיל שאומת עבור כל אחד: **משרד התחבורה והבטיחות
בדרכים** (0040), **משרד החינוך** (0020), **משרד הבריאות** (0024), **המשרד להגנת הסביבה** (0026),
**משרד הכלכלה והתעשייה** (0038). יתר המשרדים מסומנים "טרם נאסף" — במכוון לא נבנתה עבורם רשימה
משוערת.

## פריסה

`.github/workflows/deploy-pages.yml` רץ בכל push ל-`main` או ל-`claude/**`, וגם ידנית
(`workflow_dispatch`):

1. **verify** — typecheck, lint, בדיקת פורמט, בדיקות, וולידציית נתונים.
2. **build** — build סטטי והעלאת `dist` כ-artifact.
3. **deploy** — פריסה עם ה-Actions הרשמיים של GitHub Pages, והחזרת ה-URL כ-output.

`build` תלוי ב-`verify`, ולכן **כשל בדיקה או כשל ולידציית נתונים מונע פרסום**.

Pages הופעל על ה-repository (Source = GitHub Actions), ולכן שלושת ה-jobs רצים עד הסוף.

`.github/workflows/data-refresh.yml` הוא ידני בלבד. אין הרצה מתוזמנת: מקורות ציבוריים הם
תשתית משותפת, וספרי תקציב ודוחות ביצוע מתעדכנים מספר פעמים בשנה, לא שעה-שעה. הוא מריץ את
הצינור, מעלה את יומן האיסוף כ-artifact, ומבצע commit רק אם הנתונים באמת השתנו.

הגדרת Pages: `Settings → Pages → Source: GitHub Actions`.

## מגבלות ידועות

1. **אין פריטי פעילות פומבית.** API הפרסומים של gov.il דוחה בקשות אוטומטיות מזוהות ב-HTTP 403
   (הגנת bot). לא נעשה ניסיון להתחזות לדפדפן כדי לעקוף את הסירוב — זו הייתה עקיפה של סירוב מפורש
   של המקור. לכן מסך הפעילות ריק, וחלוקת הנושאים אינה מוצגת כנתון.
2. **אין נתוני כהונת שרים.** עמוד הרכב הממשלה מקוטלג אך לא אוחזר מאותה סיבה, ותאריכי כהונה אינם
   נגזרים בהסקה.
3. **נתוני התקציב אינם סופיים.** מקורם בשכבת עזר (מפתח התקציב) ולא בדוח ביצוע רשמי סגור, ולכן הם
   מסומנים "נתון חלקי" או "אומדן" ולעולם לא "ביצוע סופי".
4. **תקציב הפיתוח אינו נכלל** — ראו [מצב הנתונים](#מצב-הנתונים-בגרסה-הנוכחית).
5. **PDF ו-Excel אינם מנותחים.** ספר התקציב ודוחות הביצוע מתפרסמים כ-PDF/XLSX, וחילוץ טבלאות
   מפריסת PDF אינו אמין. המקורות נשמרים בקטלוג לאימות אנושי במקום להיות מנוחשים.
6. **רק 8 מתוך 50 מקורות אוחזרו.** אתר הכנסת מחזיר HTTP 474 לבקשות אוטומטיות. הקישורים תקפים
   ומפנים למקור; סטטוס האחזור של כל מקור מוצג במסך המקורות.
7. **12 שיעורי ביצוע חורגים מהטווח 0–150%.** אלה ערכים אמיתיים מהמקור — סעיפים קטנים, סעיפי
   הכנסה/החזר, וסעיפים שתקציבם שונה מהותית במהלך השנה. כל אחד מסומן "חריגה" בממשק ונושא הערה
   מפורשת; הוולידציה נכשלת אם ערך חורג אינו מסומן.
8. **איכות זיהוי המשרד אינה אחידה.** עבור התחבורה, החינוך, הבריאות והסביבה שם המשרד מופיע בכותרת
   מקור רשמי או בכותרת סעיף התקציב. עבור הכלכלה כותרת הסעיף היא "כלכלה ותעשייה" ולא שם המשרד
   המלא, והשיוך נשען על התאמת תחום — מסומן במפורש בעמוד המשרד.
9. **חמישה משרדים בלבד.** יתר משרדי הממשלה מסומנים "טרם נאסף"; לא נבנתה עבורם רשימה משוערת.

## כללי תרומה

- **כל נתון חייב מקור.** רשומה חדשה בלי `sourceUrl` שנפתח ומראה את הנתון לא תיכנס.
- **אין נתוני mock ב-build המפורסם.** אם נדרשים נתוני דמו לפיתוח, הם לא מגיעים ל-`dist`.
- **ערך חסר הוא `null`, לא `0`.** אפס הוא נתון בפני עצמו, ומשמעותו שהמקור אומר אפס.
- **מספר מחושב — חשבו אותו בקוד**, אל תעתיקו אותו ממקור, ותעדו את הנוסחה במסך המתודולוגיה.
- **שינוי בסכמה** מחייב עדכון של `scripts/lib/schema.ts`, של `src/types/domain.ts`, ושל
  הבדיקות.
- לפני פתיחת PR הריצו: `npm run typecheck && npm run lint && npm run format:check && npm test && npm run build`.
- מצאתם נתון שגוי או מיפוי מוטעה — [פתחו Issue](https://github.com/eyalbenzvi/GovernmentTracker/issues).
  כל תיקון נבדק מול המקור הראשוני.

## הצהרת שקיפות

אתר זה **אינו מקור רשמי ואינו מחליף את המקורות המקוריים**. הוא כלי הנגשה: הוא מפנה למקורות
הרשמיים, מתעד במדויק מה נאסף ומה לא, ומאפשר לכל אחד לבדוק כל טענה מול המקור. במקרה של סתירה
בין האתר לבין המקור הרשמי — **המקור הרשמי קובע**.

האתר אינו מפלגתי, אינו מדרג משרדים או אנשים, ואינו מסיק סיבתיות. גם כאשר מוצג קשר בין נושא
פעילות ובין סעיף תקציבי, הוא מוצג עם הראיות ועם הסתייגות מפורשת: מתאם אינו סיבתיות.
